# Neuer Tag web identity

Source: user-supplied `neuertag-styleguide.html` and `Neuer Tag Assets und Styleguide` archive, received 20 September 2026.

- Headings: locally hosted Houschka Pro, H1 Bold 700, H2 Medium 500.
- Body and UI: locally hosted Open Sans.
- H1: 32px mobile / 48px desktop, line height 1.15.
- H2: 26px / 34px, line height 1.2.
- H3: Open Sans semibold 19px / 22px, line height 1.3.
- Black headings; text #1F1F1F; muted #6B6B6B.
- Orange #FC4E13, hover #BD3A0E; backgrounds #FAF9F8 and #F1EFED; dividers #E0DDDA.
- Solid orange primary buttons, white text, full rounding. Keep 19px bold labels for large-text contrast on the supplied orange; guide's 16px semibold labels do not reach 4.5:1.
- Black outlined secondary buttons, black fill and white text on hover.
- Official supplied SVG favicon replaces the previously cropped mark.
- Color caption logo extracted from the supplied guide; footer displays it on white without recoloring.
- Project logos remain unchanged. The guide's example copy references three projects; only the two explicitly confirmed projects (Anahita and DALIA) are listed.
- Business card reviewed as a design reference. Contact information has not been imported as part of this visual update.
