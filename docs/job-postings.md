# Stellenangebote

In Sanity, open **Stellenangebote** and create a document. Set the title, URL
slug, employment type, publication date, short description and full job
information. The full description should include responsibilities, requirements,
working conditions and the organization's application instructions or contact
link. Location and SEO fields are optional.

Publish to show a card on `/mitmachen`; clicking it opens `/mitmachen/<slug>`.
Drafts, future publication dates and archived positions are excluded from the
listing, detail pages and sitemap. Content refreshes approximately every minute.
Use **Stelle geschlossen / archiviert**, then publish, to close a position.

The old non-functional application form has been removed. No application data
is collected by this feature. Existing page copy remains under **Mitmachen**;
its old action cards are no longer used as job postings. No example jobs have
been published. The Studio schema and website must both be deployed before
editors can use the new document type on the hosted Studio.
