# Anahita homepage design

Approved direction: German homepage for Anahita with warm cream backgrounds, dark green typography, orange calls to action, community photography, and generous whitespace.

This delivery is a design preview in the existing Next.js application. It includes the header, responsive navigation, hero, projects, introduction, news, participation options, help information, and footer. Organization-specific copy and project examples are explicitly drafts; no invented numbers, contact details, legal claims, or live payment/form behavior. Editorial preview data lives outside React components and will be replaced by Sanity in the production phase. Preview indexing is disabled.

Use existing Next.js, TypeScript, and Tailwind. Keep page composition small, server-render sections, and limit client code to navigation. Use semantic headings, focus states, large tap targets, and local optimized imagery. All preview links must resolve to meaningful sections or a clearly explained information page.
